# Htet Ein Yan

Static portfolio. GitHub Pages serves this repository from the `main` branch, root directory, at [https://einyan03.github.io](https://einyan03.github.io).

Open `index.html` in a browser, or from this folder:

```sh
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.
